# Tools

O registro persistido contém criação de arquivos, leitura de arquivos escolhidos, pesquisa de memória, pesquisa de conhecimento e informações locais de data e sistema. Cada item registra ativação e política de permissão.

Leitura e escrita exigem uma escolha explícita na interface. Busca local pode ocorrer automaticamente quando habilitada. A geração de artefatos é implementada pelo `ArtifactService`; MCP amplia a lista mediante configuração.
